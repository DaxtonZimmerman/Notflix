# NOTFLIX — Class project

Open `index.html` in a browser. No installation or account is needed. Upload the whole folder when submitting; keep `images`, `css`, and `js` beside `index.html`.

Includes all 28 fictional titles, original posters and text-free banners, responsive navigation, title/description search, genre filters, movie/show browsing, movie detail dialogs, and My List saved locally in your browser.

“Play preview” runs a 24-second animated artwork showcase with pause, replay, and seek controls. These are fictional movies, so there are no full films or real streaming accounts. No audio is included.

The page uses local CSS so its layout works without an internet connection or a build step. All artwork is included locally. The project is not affiliated with Netflix or any movie studio.
